ECMT Drill — версия для телефона (веб-приложение, работает без интернета)

Телефон не умеет устанавливать приложение из файла — нужно один раз выложить эту папку
на бесплатный хостинг. Проще всего GitHub Pages (5 минут, с компьютера):

1. Зарегистрируйтесь на github.com (бесплатно).
2. Справа вверху «+» → New repository. Имя: ecmt-drill. Тип: Public. Create repository.
3. На странице репозитория нажмите «uploading an existing file».
4. Перетащите в окно ВСЁ содержимое этой папки: index.html, manifest.webmanifest, sw.js
   и папку icons (именно содержимое, а не саму папку ecmt-drill). Нажмите Commit changes.
5. Settings → Pages → Source: «Deploy from a branch» → Branch: main, папка / (root) → Save.
6. Через 1–2 минуты сайт будет по адресу  https://ВАШ-ЛОГИН.github.io/ecmt-drill/

На телефоне:
  iPhone (Safari): откройте адрес → «Поделиться» → «На экран „Домой"».
  Android (Chrome): откройте адрес → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
После первого открытия приложение работает и без интернета. Прогресс хранится на телефоне.

Перенос прогресса: кнопка «Перенос прогресса» над карточками (код из одной версии вставляется в другую).
Проверка письменных ответов: кнопка «Скопировать запрос для Claude» → вставить в любой чат с Claude,
либо самопроверка по эталону.

Обновление: если пришлю новую версию — загрузите новый index.html в тот же репозиторий
(Add file → Upload files), телефон подхватит её при следующем открытии с интернетом.

Важно: сайт на GitHub Pages открыт всем, у кого есть ссылка.
